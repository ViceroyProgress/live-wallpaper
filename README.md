## About
<img src="/resources/main_preview.gif" width="600" height="338"/>

Animated desktop wallpapers, bring your desktop to life!

## Features

- **Video wallpaper.** Set any video or GIF as your desktop background with hardware-accelerated playback.
- **Interactive wallpapers.** Use webpages, Shadertoy links, and even Unity or Godot games as animated wallpaper for PC.
- **Drag and drop setup.** Add a file or link to the app and it becomes your wallpaper instantly.
- **Smart performance.** Playback pauses when a fullscreen app or game is running, on battery power, or during a remote desktop session.
- **Screensaver mode.** Turn any live wallpaper into a Windows screensaver.
- **Multi-monitor support.** Set different wallpapers on different screens.
- **Free and open source.** A true Wallpaper Engine free alternative with no paywalled features.
- **Automation and API.** Control the app from the command line or scripts, and build your own interactive wallpapers.

## Supported Wallpaper Types

- Video files
- GIF animations
- Webpages and web apps
- Shadertoy links
- Unity games
- Godot games

## Performance

- Hardware-accelerated video playback.
- Automatic pause when a fullscreen app or game is running.
- Automatic pause when running on battery power.
- Automatic pause during a remote desktop session.
- CPU and GPU usage stays near zero while playback is paused.

## System Requirements

- Windows 10 or Windows 11
- A GPU with hardware video decoding support (recommended)

## Usage

### Set a wallpaper

1. Drag and drop a video, GIF, or file into the app, or paste a link.
2. The wallpaper is applied to your desktop instantly.

### Use multiple monitors

1. Open the monitor settings.
2. Choose a different wallpaper for each screen.

### Use a wallpaper as a screensaver

1. Open the screensaver settings in the app.
2. Select any live wallpaper to use as your Windows screensaver.

### Automation and API

Control the app from the command line or scripts, and build your own interactive wallpapers. See the [documentation](../../wiki) for details.
